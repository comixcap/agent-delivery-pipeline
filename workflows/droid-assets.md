# /droid-assets — внедрение дизайнерских ассетов

Что внедряем (какой экран/элемент, особые пожелания из чата заказчика): $ARGUMENTS

**Прочитай раздел «Ассеты от дизайнеров» в `$HOME/.claude/rules/android-games.md`.**

Порядок — строго этот, он снимает 90% переделок:

1. Файлы — в `~/Downloads`. Каждый посмотреть глазами (Read) + `sips` (размер, alpha).
   Составить таблицу: файл → что изображено → куда идёт.
2. **Замерить bbox видимого контента** по альфе (python3 + PIL) у КАЖДОГО спрайта.
   Обрезать по контенту (ffmpeg crop) — прозрачные поля генерённых PNG ломают вёрстку.
3. Фоны сжать (ffmpeg scale, jpg если нет прозрачности). Имена в drawable: `[a-z0-9_]`.
4. Определить подвижные части. Всё, что движется, — рисуется НАТИВНО в стиле ассета;
   если подвижный элемент впечатан в спрайт — расшить (крой/зеркало). Зоны логики и
   визуала — одни доли одной оси (общая переменная центра/направляющей).
5. Вёрстка поверх подложки: BoxWithConstraints, размеры — доли подложки, аспекты — из
   РЕАЛЬНЫХ обрезанных пикселей. Кнопки-ассеты кликабельны с scale-прижатием.
6. Собрать, отдать оператору на скриншот. Полученные правки вносить, меняя ОДНУ
   именованную константу на замечание — система координат уже точная.
